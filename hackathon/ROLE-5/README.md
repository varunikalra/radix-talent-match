
# Role 5: Skill Matching Engine (RADIX Talent Match)

The Skill Matching module evaluates candidate profiles against target job requirements to generate compatibility scores and capability insights.

## 📂 Folder Structure

- `matches/`: Stores generated JSON skill match reports for each candidate.
- `skill_matcher.py`: Core scoring logic script.
- `batch_matcher.py`: Batch runner for all sample candidates.
- `api.py`: FastAPI backend endpoints.
- `requirements.txt`: Project dependencies.

## 🚀 Getting Started

1. Install dependencies:
   ```powershell
   pip install -r requirements.txt
   ```
