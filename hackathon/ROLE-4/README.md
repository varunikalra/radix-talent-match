
# Role 4: Talent Check (RADIX Talent Match)

The Talent Check module automatically validates candidate profiles against standard eligibility criteria (verifying education records, skill sets, and compliance rules) and saves audit reports.

## 📂 Folder Structure

- `checks/`: Stores generated JSON audit reports for each candidate.
- `talent_check.py`: Core evaluation logic script.
- `run_all_checks.py`: Batch evaluation script for all sample candidates.
- `api.py`: FastAPI backend endpoints for running and retrieving talent check reports.
- `requirements.txt`: Project dependencies.

## 🚀 Getting Started

1. Install dependencies:
   ```powershell
   pip install -r requirements.txt
   ```
